# Check catalog

`checks/catalog.json` is the scoring spec. The agent evaluates every criterion with Read, glob, and grep only. Do not install packages. Do not run `npx`. Do not run tests, linters, or scanners.

The seven pillars are Style & Validation (`style-linting`), Testing, Documentation, Developer Environment, CI/CD, Code Health, and Security. Display names are user-facing; scoring keys are the ids. Do not add a ninth pillar.

v1 skips `requiresLLM` criteria. Those are a third state: skipped, excluded from the denominator, not fails. Keep `v1SkipLLM`.

## How to evaluate a row

1. If `requiresLLM` is true, mark skipped.
2. Else look for files in `anyFiles` / `anyGlobs` (file or directory presence).
3. Else read listed files and grep `fileContains` / `fileRegex` / `ciGrep`.
4. Else apply special fields: `minBytes`, `tsconfigStrict`, `languagesPass`, `packageJsonPath`, `makefileTarget`, `lockFileFreshDays`, `testFiles`, `ciFiles`.
5. Presence of config is a pass. Never execute the tool the config describes.

Well-known config filenames in `anyFiles` / `fileContains` (no slash) match at the repo root or any walked path with that basename, so `docs/CODEOWNERS`, `packages/app/AGENTS.md`, `apps/web/biome.json`, `packages/lib/tsconfig.json`, and `assets/eslint.config.js` count without listing every monorepo path. No-slash globs such as `eslint.config.*` / `.eslintrc.*` / `.prettierrc.*` / `vitest.config.*` / `jest.config.*` match the basename at any depth for `linter`, `formatter`, and `test-framework`. Other ids keep no-slash globs root-anchored (`*.csproj` matches `Lib.csproj`, not `Src/Lib/Lib.csproj`; a vendored `deps/**/*.sln` is not a `setup-script`). Exact relative paths (`.cursor/environment.json`, `.github/CODEOWNERS`) stay exact; slashed globs still use the walked file list. `env-documentation` skip signals stay repository-root only (nested `sample/**` / `examples/**` / `integration/**` compose does not force the check); a nested `.env.example` may still pass as a real example file. `IGNORE_DIRS` (`node_modules`, `vendor`, `dist`, `build`, `.git`, `coverage`, and the rest) still apply, so `node_modules/foo/tsconfig.json` does not count.

`ai-context` looks for `AGENTS.md`, `.github/AGENTS.md`, `CLAUDE.md`, `.cursor/rules`, `.cursorrules`, `.github/copilot-instructions.md`, `GEMINI.md`, `.github/instructions/**/*.md`, `.windsurfrules`, and `WARP.md`. `AGENTS.md` is the preferred first-hit when both `AGENTS.md` and `CLAUDE.md` exist. When the check fails, the file to add is `AGENTS.md`. Do not add LLM scoring.

## Levels

1 Functional, 2 Documented, 3 Standardized, 4 Optimized, 5 Autonomous.

Every level clears at 80% of its own counted rows, including L1. L1 Functional is readme, linter, test-files-exist, and type-checker (skip when there is no conventional checker file). license and lock-file are L2. Minimum level is 1. Non-AI counts: L1=4 need 4 (3/3 when type-checker skips), L2=13 need 11 (12 need 10 when `editorconfig` skips because a linter already passes), L3=10 need 8, L4=8 need 7, L5=1 need 1 (`bundle-analysis`). If the report would show Level 5, add the disclaimer. Do not celebrate Autonomous. Eval canvas copy prints those engine labels. A high-% repo still at level 1 because the L2 sequential gate failed gets a "would be L2 except …" line naming remaining L2 fail ids (not `l1CapReasons`; that field is only when `l1Capped` is true). `editorconfig` skips when a prescriptive linter is already configured; do not dummy `.editorconfig`. Todo ranking is already gate-first; do not lead with `editorconfig` if it is skipped.

Optional helper: `node scripts/code-readiness.mjs <repo>` applies this same catalog with Node `fs` only. No npm install.
